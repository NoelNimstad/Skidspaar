# Skidspår (Spår)

> [!warning] Spår is early in development!

## About
Skidspår (Cross-country skiing trail) is a cross platform (through SDL3) Vulkan based 2D game framework for C++. The goal of Spår is to allow for efficient (performance & time-wise) development of games in C++. By abstracting and creating a shell around Vulkan, it opens up development to those who don't have time for the 1000-LoC-for-a-triangle nature of Vulkan.
